Description

What is Inventor?

Autodesk Inventor is professional mechanical design software used for parametric modelling, assemblies, drawings, simulation, and manufacturing documentation.

Main features

  • Parametric and direct 3D solid modelling for parts and assemblies.
  • Sheet-metal, frame, tube-and-pipe, cable, and harness workflows.
  • Drawing generation from 3D models.
  • Simulation and design-analysis tools appropriate to supported editions.
  • Integrated CAD/CAM and manufacturing workflows.
  • Interoperability with AutoCAD, Revit, and common engineering formats.

Release considerations
